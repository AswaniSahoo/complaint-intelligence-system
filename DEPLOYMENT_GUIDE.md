## Quick Start Guide

### Local Development
1. Clone repo and install dependencies: `pip install -r requirements.txt`
2. Add API key to `.env`: `GEMINI_API_KEY=your-key`
3. Run dashboard: `streamlit run app/app.py`
4. Open browser at http://localhost:8501
